# Spot Ether ETP exchange-listing approval note

Date: 2024-05-23
Source: SEC order
URL: https://www.sec.gov/file/34-100224

The SEC granted accelerated approval for proposed rule changes to list and trade shares of ether-based exchange-traded products.
For ETH, this is a positive policy and liquidity event because regulated exchange-traded products can improve access, institutional adoption, and inflow potential.
The note mentions ETH directly so the ingestion pipeline should map it to ETHUSDT.
